Powered by Firebase & GitHub Pages

GitHub Pagesでの公開とFirebase準備の手順

重要：ログインエラー（auth/unauthorized-domain）を防ぐため

Firebase Consoleで、GitHub Pagesのドメインを許可リストに追加する必要があります。

  1. FirebaseでGoogle認証とドメインの設定
    • Firebase Console にアクセス。
    • 「Authentication」 > 「Sign-in method」で Google を有効化。
    • 「Authentication」 > 「設定」 > 「承認済みドメイン」を開き、GitHub PagesのURL（例: your-name.github.io）を追加。
  2. Cloud Firestoreデータベースの作成
    • 「Firestore Database」を作成。
    • 「ルール」タブで以下のように読み書き権限を設定してください： 
      rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /feedback/{document} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update: if request.auth != null;
    }
  }
}
  3. GitHub Pagesへのデプロイ
    • このファイルを index.html という名前で保存。
    • GitHubリポジトリを作成し、index.html をコミット&プッシュ。
    • Repository Settings > Pages にて、Sourceを main (または master) ブランチの `/root` に設定してSave。
